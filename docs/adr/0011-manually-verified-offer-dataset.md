# 商品报价采用人工核验数据集，不接爬虫或电商 API

> 状态：**已被 [ADR 0021](0021-rule-based-offer-verification.md) 取代**——核验方式改为确定性规则，本文件的人工核验条款失效；人民币分、购买链接与「无报价不得进入成功方案」的结论继续有效。

## 背景

现有硬件数据包含 8,238 条 PCPartPicker 记录与 25,318 条 PassMark 记录，但价格是 2026-10 的美元快照，购买链接指向 PCPartPicker 详情页，没有中国区商家、平台商品 ID 或人民币报价。方案要求展示"商家 / 平台 / 核验报价 / 购买链接 / 核验时间"，并把预算作为严格上限。

## 决策

本期使用人工维护的中国区商品报价数据集，由项目负责人提供现成清单，按 `docs/planning/pc-config-implementation-plan.md` §7.3 的字段录入。每条报价必须人工核验，`match_status` 必须为 `VERIFIED` 才能进入推荐；金额统一为人民币分。

## 考虑过的替代方案

- **美元参考价 × 汇率折算**：零人工，但会把非中国区、非实时价格包装成"核验报价"，直接违背预算与真实性要求。
- **接入电商开放平台或爬虫**：数据新鲜度最好，但涉及资质、合规、反爬与维护成本，超出本期范围。
- **商业商品数据供应商**：数据质量高，但需要采购与对接周期。

## 影响

- 数据新鲜度依赖人工维护，必须在结果中展示 `verified_at` 并给出价格免责声明。
- 商品数据通过 `OfferRepository` 访问；未来切换 PostgreSQL 或自动匹配服务时，不改变 Agent 工具契约。
- 没有有效报价的硬件不得进入成功方案，也不得用相似型号替代。
