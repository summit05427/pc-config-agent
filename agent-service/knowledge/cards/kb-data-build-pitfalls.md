# 从数据集字段归纳的装机陷阱

## 结论

- 内存代际不能混插：主板的 `memory_type` 只有单一取值，DDR5 主板 543 条、DDR4 主板 211 条；内存条同样分为 DDR5 883 条、DDR4 584 条，不存在同时支持两代的记录。
- 机箱限长与显卡长度存在错配区间：180/1072（16.8%）的机箱显卡限长低于 340 mm，99/1072（9.2%）低于 320 mm；而 53/1085（4.9%）的显卡长度超过 340 mm，168/1085（15.5%）超过 320 mm。
- 电源接口要按显卡核对：213/1109（19.2%）的显卡需要 16-pin 12VHPWR，336/518（64.9%）的电源至少带 1 个该接口，仍有 182 条电源完全不提供。
- 高功耗显卡要预留功率：272/1109（24.5%）的显卡 TDP 不低于 300 W，显卡 TDP 的 P95 为 360 W；电源侧 850 W 及以上占 59.8%。
- 存储端口容易被 M.2 挤占：650/750（86.7%）的主板至少有 2 个 M.2，81/781（10.4%）的主板 SATA 端口不超过 2 个，57/781（7.3%）同时满足“至少 2 个 M.2 且 SATA 不超过 2 个”。

## 数据依据

- 数据文件：`pcpp_memory.csv`、`pcpp_motherboard.csv`、`pcpp_gpu.csv`、`pcpp_case.csv`、`pcpp_psu.csv`、`pcpp_cooler.csv`、`pcpp_cpu.csv`（均为 2026-10-05 快照）。
- 过滤规则：价格统计统一剔除 `price<=0` 与各表 P99 以上长尾；交叉统计中的比例使用全表行数作分母，字段缺失会单独标注。
- 内存代际来自主板 `memory_type` 与内存 `speed` 的前缀；机箱限长来自 `maximum_video_card_length`（缺失 26/1098），显卡长度来自 `length`（缺失 24/1109）。
- 供电接口来自显卡 `external_power` 与电源 `pcie_16_pin_12_vhpwr_12_v_2x6_connectors`；功耗来自两张表的 `tdp` 字段。
- M.2 与 SATA 数量来自主板 `m_2_slots`（缺失 31/781）与 `sata_6_0_gb_s_ports`；数据集没有“M.2 与 SATA 共享通道”字段，只能提示端口数量层面的风险，是否共享需查主板手册。
- 散热器插槽支持率：AM5 761/863（88.2%）、LGA1851 750/863（86.9%）、LGA1700 750/863（86.9%）、AM4 792/863（91.8%）。
- CPU 与主板插槽按字符串精确比对，54/493（11.0%）的 CPU 插槽没有出现在主板表中，主要是老平台。
- 机箱数据没有 CPU 散热器限高字段，散热器限高无法从本数据集校验。

## 使用建议

- 用于在方案初筛阶段列出必查项：内存代际、显卡长度、电源接口与功率、M.2/SATA 端口、CPU 与散热器插槽。
- 每条结论都对应具体字段，换用新快照时应重算；比例会随样本更新而变化。
- 涉及“是否共享通道”“机箱限高”“散热器解热能力”等数据集没有的字段，必须查厂商规格或评测，不能从本卡片推断。
- 价格与在售状态变化快，装机前以实时报价和官方规格为准。
