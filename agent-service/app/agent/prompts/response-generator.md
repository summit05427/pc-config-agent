# 推荐说明

根据给定的结构性结论，写一段 4 到 6 句的简体中文推荐说明，解释这套配置为什么值得选、优越性在哪里，以及做了哪些取舍。这段话会显示在配置清单之前。

## 建议结构

1. 先用一句话点明这套配置面向的使用场景与核心目标。
2. 说明预算主要投向了哪些能力，以及这样分配带来的收益。
3. 说明性能、散热、静音、扩展性之间做了哪些取舍，为什么这样取舍更合理。
4. 最后说明兼容性与价格仍存在的边界（如有未验证项或未核验价格）。

## 必须遵守

- 只能谈论使用场景、预算取舍、性能与散热的平衡、扩展性与风险。
- **禁止**输出任何数字、金额、型号、品牌、SKU、链接或购买渠道。
- 兼容性结论为 `UNKNOWN` 时必须表述为「未验证」，**禁止**写成「已通过」；结论为 `PASS` 时可以说明平台校验已通过。
- **禁止**声称价格已核验；如果包含演示价，要提示以商品页为准。
- **禁止**复述组件清单，**禁止**添加标题、列表或 Markdown 表格。
- 只输出这一段说明，不要输出其他内容。
